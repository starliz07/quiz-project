## 6. Использованные команды Git
| Команда | Назначение |
|---------|-----------|
| `git clone` | Клонирование удалённого репозитория на локальный компьютер |
| `git config --global user.name` | Установка имени пользователя для коммитов |
| `git config --global user.email` | Установка email для коммитов |
| `git status` | Просмотр состояния рабочей директории и staging-области |
| `git add` | Добавление файлов в staging-область перед коммитом |
| `git commit -m` | Создание коммита с сообщением |
| `git push` | Отправка локальных коммитов в удалённый репозиторий на GitHub |
| `git pull` | Получение и слияние изменений с удалённого репозитория |
| `git checkout main` | Переключение на ветку main |
| `git checkout -b` | Создание новой ветки и переключение на неё |
| `git branch` | Просмотр списка локальных веток |
| `git branch -d` | Удаление локальной ветки после merge |
| `git merge` | Слияние одной ветки с другой |
| `git log --oneline` | Просмотр истории коммитов в кратком виде |
| `git log --oneline --graph --all --decorate` | Просмотр графа всех коммитов с ветвлениями и метками |
| `git rm` | Удаление файлов из репозитория |
| `git fetch` | Загрузка изменений из удалённого репозитория без слияния |
| `git tag -a` | Создание аннотированного тега версии |
